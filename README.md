# Vaema Nails — Simulación Web Interactiva (Elche)

Versión estática e interactiva de **Vaema Nails** preparada para visualizarse directamente en navegador o mediante **GitHub Pages** sin necesidad de base de datos ni servidor backend.

## Estructura del repositorio

- index.html: Punto de entrada principal de la aplicación.
- css/styles.css: Tipografías, paleta cromática y animaciones de entrada.
- js/data.js: Estado inicial y datos del estudio en Elche (servicios de uñas, cursos presenciales, convocatorias, galería y horarios).
- js/app.js: Motor interactivo de vistas, filtros, asistente de reservas de 4 pasos con anticipo del 50 %, modal de inscripción a cursos, inicio de sesión unificado (clienta / administradora) y panel de administración con subida de fotos desde el dispositivo.
